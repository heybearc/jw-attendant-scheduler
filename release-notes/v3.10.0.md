# What's New in Version 3.10.0

**Released:** February 4, 2026

---

## ✨ New Features

### Department Template Management

You can now assign and change department templates for existing events! This gives you more flexibility in managing your events after they're created.

**What you can do:**
- Assign a department template to events that don't have one
- Change the template for an event if your needs change
- Remove a template to enable all features

**How to use it:**
1. Go to any event you manage
2. Click "Edit Event"
3. Find the "Department Template" dropdown
4. Select the template you want (or "No template" for all features)
5. Save your changes

The event will immediately update to show or hide features based on the template you selected.

---

## 🎯 Improvements

### Better Template Enforcement

Events now properly respect their department template settings. If a module (like Count Times or Lanyards) is disabled in your department template, you won't see any buttons, links, or sections related to that feature.

**What this means for you:**
- Cleaner interface - only see what's relevant to your department
- No confusion about which features to use
- Consistent experience across all events using the same template

**Examples:**
- **Audio/Video departments** won't see Count Times or Lanyards features
- **Baptism departments** can focus on positions without extra clutter
- **Parking departments** see only what they need

## 💡 What You Need to Know

**No action required!** These improvements work automatically.

**If you manage events:**
- You can now edit existing events to assign or change their department template
- Check the "Department Template" dropdown on the event edit page
- Templates control which features are visible for that event

**If you use events:**
- You'll only see features that are relevant to your department
- If you don't see a feature you expect, check with your event administrator about the department template
