# What's New in Version 4.12.0

**Released:** February 18, 2026

---

## 🧹 Code Cleanup & Simplification

This release focuses on removing deprecated features and simplifying the system architecture.

### Removed Deprecated Features

We've removed several deprecated admin pages and features that were replaced by the new event-centric configuration system (introduced in v4.11.0):

**Removed Admin Pages:**
- Department Templates page
- Assignment Templates pages
- Position Extraction tools

**Removed Event Page:**
- Position-level Oversight page (replaced by event-level oversight in Edit Event page)

**What you'll see:**
- Cleaner admin navigation with fewer unused options
- Simplified event navigation tabs
- All functionality preserved through the new event settings system

---

## 💡 What You Need to Know

**No action required!** All changes are backward compatible:
- Existing events continue to work exactly as before
- All your data is preserved
- Event settings (introduced in v4.11.0) provide all the same functionality
- Event cloning replaces template functionality with more flexibility

**What changed:**
- Removed 14 files and 3,555 lines of deprecated code
- Simplified navigation menus
- Reduced system complexity

**If you were using templates:**
- Your existing event configurations are preserved in event settings
- Use the "Clone Event" feature to duplicate event structures
- Configure modules and settings per event in the Edit Event page

---

## 🔧 Technical Improvements

- Reduced codebase complexity by removing template abstraction layers
- Improved maintainability with cleaner architecture
- Better performance with fewer unused code paths
- Simplified mental model for event configuration
