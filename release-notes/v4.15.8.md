# What's New in Version 4.15.8

**Released:** April 11, 2026

---

## 🐛 Bug Fix

### Early Check-In Tab Now Shows for All Volunteers

Fixed an issue where the Early Check-In tab was not appearing on volunteer dashboards even when the IVS (International Volunteer Services) module was enabled for their event.

**What was wrong:**
- The previous fix (v4.15.6) was too restrictive
- It only showed the Early Check-In tab for volunteers who went through the IVS approval workflow
- Regular volunteers at events with IVS enabled couldn't see the tab

**What's fixed:**
- Early Check-In tab now appears for ALL volunteers when the IVS module is enabled for their event
- No longer requires special IVS approval workflow fields
- Works correctly for both IVS-approved volunteers and regular volunteers

**How it works now:**
1. Admin enables IVS module in event settings
2. All volunteers registered for that event see the Early Check-In tab on their dashboard
3. Volunteers can access early check-in features when available

---

## 💡 What You Need to Know

- **No action required** - The fix is automatic
- **For admins:** If you have IVS module enabled for an event, all volunteers will now see the Early Check-In tab
- **For volunteers:** If your event has early check-in available, you'll see the tab on your dashboard
