# What's New in Version 4.5.0

**Released:** February 10, 2026

---

## ✨ New Features

### 📅 Event Creation Help & Onboarding

**New coordinators now have step-by-step guidance!**

We've added comprehensive help documentation to make it easier for new OVERSEER users to create their first event.

**What you'll see:**
- 💡 Help banner on the event creation page with a link to the guide
- 📖 Complete step-by-step guide covering all aspects of event creation
- 🎯 Explanations of department templates and module options
- ❓ Common questions and answers
- 💡 Tips and best practices throughout

**How to access it:**
1. Go to the event creation page
2. Click "View Step-by-Step Guide" in the blue help banner
3. Or visit the Help Center and select "Creating Your First Event"

**Who benefits:** OVERSEER, ASSISTANT_OVERSEER, and KEYMAN users creating events

---

### 🎛️ Event-Level Module Customization

**Customize which features appear for each event!**

You can now enable or disable specific modules for individual events, giving you more control over your event's interface.

**What you can do:**
- Toggle Count Times, Lanyards, and IVS Approvals modules on or off
- Customize modules when creating a new event
- Keep your event interface clean and focused on what you need
- Different events can have different module configurations

**How to use it:**
1. When creating an event, select a department template
2. You'll see checkboxes for available modules
3. Uncheck any modules you don't need for this event
4. The unchecked modules won't appear in your event navigation

**Example:** For a small event, you might disable Lanyards and IVS Approvals to simplify the interface, keeping only Count Times enabled.

**Who benefits:** OVERSEER and ASSISTANT_OVERSEER users creating events

## 🔧 Improvements

### Department Template Access for OVERSEER Users

**OVERSEER users can now see and select department templates when creating events.**

Previously, only ADMIN users could view department templates. Now OVERSEER and ASSISTANT_OVERSEER users can:
- View all available department templates
- Select templates when creating events
- See template descriptions and features

**Note:** Only ADMIN users can create or modify templates. OVERSEER users can select from existing templates.

We've improved the reliability of the location search and creation features:

**What you'll notice:** Location search and creation should work more smoothly and reliably.
