# What's New in Version 4.15.3

**Released:** February 20, 2026

---

## 🔒 Security Improvements

### Authentication Library Updated
Updated the authentication library (NextAuth) to the latest version, which addresses a known security vulnerability in versions 4.24.11 and earlier.

### Email Library Updated
Updated the email sending library (Nodemailer) to the latest major version, resolving a reported security issue and improving compatibility with the updated authentication library.

### MCP SDK Updated
Updated the Model Context Protocol SDK to version 1.26.0, fixing a ReDoS (Regular Expression Denial of Service) vulnerability and a cross-client data leak issue.

### Dependency Chain Vulnerabilities Resolved
Resolved a cascade of security vulnerabilities in AWS SDK and related packages that were triggered by the outdated dependencies above.

### OS Security Patches Applied
Applied all available Ubuntu 22.04 LTS security patches to both production servers, including updates to glibc, GnuPG, AppArmor, and DNS libraries.

---

## 💡 What You Need to Know

- No action required — all updates are internal security hardening.
- No user-facing functionality has changed.
- Application behavior is identical to v4.15.2.
