# What's New in Version 4.1.0

**Released:** February 7, 2026

---

## ✨ Enhanced Feedback System

We've significantly improved how you submit and track feedback!

### 📋 Feedback ID Numbers

Every feedback item now gets a unique ID number (like **FB-001**, **FB-002**) that makes it easy to reference and track.

**What you'll see:**
- Each feedback item displays its ID number in a dark badge
- IDs appear in both the feedback list and detail views
- You can reference feedback by ID when discussing with admins

**Why this helps:**
- Easy to say "See FB-042" instead of describing the issue
- Track your feedback items more easily
- Know exactly which item is being discussed

---

### ✅ Resolution Comments

When your feedback is marked as resolved, you'll now see a clear explanation of what was done.

**What you'll see:**
- A green box at the top of resolved feedback items
- Clear explanation of how the issue was fixed
- Details about what changed or why a decision was made

**Why this helps:**
- Know exactly what was done to address your feedback
- Understand why certain decisions were made
- See commit references and version information

---

### 🔒 Admin Improvements

For administrators managing feedback:

**Resolution Comments Required:**
- Admins must now provide a resolution comment when marking feedback as resolved
- Ensures users always know what happened with their feedback
- Maintains clear communication and accountability

**Better Tracking:**
- All feedback items have sequential ID numbers
- Resolution comments stored for future reference
- Improved feedback history and audit trail

---

## 🐛 Bug Fixes

### Combined Shift + Oversight Operations (FB-012)
Fixed bulk operations for creating shifts with oversight assignments in one step.

### Complete Schedule Visibility (FB-003)
Volunteers can now see their complete schedule across all events.

### Assignments Column Display (FB-004)
Added assignments column to volunteers table for better visibility.

---

## 💡 What You Need to Know

**No action required** - all improvements are automatic!

**Using the new features:**
1. Submit feedback as usual through the **Send Feedback** button
2. Your feedback will automatically get an ID number
3. When resolved, you'll see a clear explanation in the green resolution box
4. Reference feedback by ID (e.g., "FB-042") when needed

**For Admins:**
- You must provide a resolution comment when marking feedback as resolved
- This ensures users always understand what happened with their feedback
