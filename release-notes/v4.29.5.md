# What's New in Version 4.29.5

**Released:** July 27, 2026

---

## 🐛 Bug Fixes

### Mobile Early Check-In works again
On the volunteer phone dashboard, **Check-In** in the bottom bar looked greyed out and showed no people for any day.

**What changed:**
- Check-In opens for the event you already selected
- The list uses the same IVS Early Check-In access rules as the desktop tab
- Outside Fri–Sat–Sun, the list defaults to Friday so you can prep ahead
- If the list cannot load, you see a clear message instead of a blank screen

---

## 💡 What You Need to Know

- Check-In stays available for IVS team members (and staff with IVS access)
- If Check-In is still grey, confirm you have an event selected and IVS Early Check-In rights for that event
