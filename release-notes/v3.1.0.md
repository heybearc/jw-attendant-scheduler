# What's New in Version 3.1.0

**Released:** January 4, 2026

**Phase 3 Complete: Template-Driven Department System** 🎉

This update completes Phase 3 of our roadmap, bringing powerful new features that make event management faster, easier, and more customized to your department's needs.

---

## ✨ New Features

### 🎯 Department Templates

**What it is:**
Department templates customize your event experience based on which department is managing it. Each template controls what features you see, what terminology is used, and what information is needed.

**What you can do:**
- Choose from pre-configured templates (Attendants, Baptism, Parking, etc.)
- See only the features relevant to your department
- Use department-specific terminology automatically
- Get custom fields for your department's unique needs

**How to use it:**
1. When creating an event, select a department template at the top of the form
2. The form will show custom fields specific to that department
3. Your event will automatically use the right features and terminology

**Example:** An Attendants event shows Count Times and Lanyards, while a Baptism event focuses on candidate tracking and interview scheduling.

---

### 📋 Position Templates

**What it is:**
Create multiple positions instantly instead of adding them one by one. Each department template includes pre-configured positions ready to use.

**What you can do:**
- Create 5+ positions with a single click
- Use pre-configured positions specific to your department
- Save time on event setup
- Still customize positions after creating them

**How to use it:**
1. Go to your event's Positions page
2. Click the purple "📋 Create from Template" button
3. Select which positions you want to create
4. Click "Create" and all positions are ready!

**Example:** For an Attendants event, create Main Entrance, Upper Level, Lower Level, Stage Area, and Contribution Boxes positions all at once.

---

### 📝 Custom Fields

**What it is:**
Department-specific information fields that appear on your event creation form and event details page.

**What you can do:**
- Track department-specific information (badge numbers, lot assignments, candidate names, etc.)
- See custom fields automatically based on your department template
- View all custom information on the event detail page

**How to use it:**
1. Select a department template when creating an event
2. Fill in the custom fields that appear
3. View the information anytime on your event detail page

**Examples:**
- **Attendants:** Badge Number, Section Assignment
- **Baptism:** Candidate Name, Interview Date, Baptism Date
- **Parking:** Lot Assignment, Vehicle Count

---

### ⭐ Saved Filter Presets

**What it is:**
Save your frequently used filter combinations and apply them with one click instead of setting up filters every time.

**What you can do:**
- Save filter combinations you use often
- Apply saved filters with one click
- Create unlimited presets per event
- Delete presets you no longer need

**How to use it:**
1. On the Attendants page, set up your filters
2. Click "💾 Save Current Filters"
3. Give it a name (e.g., "Active Elders")
4. Next time, click "⭐ Show Filter Presets" and apply it instantly

**Examples:**
- "Active Elders" - Status: Active, Role: Elder
- "Pioneers" - Status: Active, Role: Pioneer
- "Main Congregation" - Congregation: Main, Status: Active

---

### 🔤 Dynamic Terminology

**What it is:**
The system now uses different terminology based on your department template.

**What you'll see:**
- Attendants events say "Attendant" and "Post"
- Other events say "Volunteer" and "Position"
- Terminology changes throughout the entire system automatically
- Consistent language that matches your department

**No action needed** - this happens automatically based on your event's department template!
