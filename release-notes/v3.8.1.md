# What's New in Version 3.8.1

**Released:** February 1, 2026

---

## 🐛 Bug Fixes

### User Management Terminology Corrections

Fixed several issues where the old "attendant" terminology was still appearing instead of the updated "volunteer" terminology throughout the admin portal.

**What was fixed:**
- User management page now correctly displays "volunteer" instead of "attendant"
- Edit user page now shows linked volunteer information properly
- Volunteer linking now persists correctly when saving user changes
- All dropdown menus and labels updated to use "volunteer" terminology

**What you'll notice:**
- Consistent "volunteer" terminology throughout the application
- Volunteer links display correctly in both list and edit views
- No more "No attendant linked" messages - now shows "No volunteer linked"

---

## 🔧 Technical Fixes

### Event Management API Corrections

Fixed internal database references that were causing errors when creating or editing events.

**What was fixed:**
- Event creation now works without errors
- User editing now works without errors
- Database queries updated to use correct field names
