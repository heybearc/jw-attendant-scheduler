# What's New in Version 4.29.0

**Released:** July 26, 2026

---

## ✨ New Features

### Multi-person shifts (regional stations)
You can set how many volunteers are needed on a single shift—for example 4 people at one station—without creating separate positions for each person.

**What you can do:**
- Set **Need** when adding a shift, or when editing an existing one
- See fill progress like `2/4` on each shift
- Use auto-assign to fill remaining open slots (not just the first empty seat)

**How to use it:**
1. Open an event → **Positions**
2. Add or edit a shift and set **Volunteers needed** (default stays 1 for existing events)
3. Assign people as usual until the shift shows full

### Edit shifts in place
Fix a wrong name or time without deleting and recreating the shift.

**How to use it:**
1. On a position card, click **Edit** next to the shift
2. Change name, start/end time, All Day, or Need
3. Save — the list reorders automatically

### Shifts sort morning to evening
Shifts on a position are ordered by start time (AM → PM). All Day shifts appear at the end. Order updates when you create, edit, or delete a shift.

## 💡 What You Need to Know

- Existing events keep **1 person per shift** unless you raise **Need**
- For rotating overseers per shift, assign an **Overseer** role on that shift; position-level oversight remains the overall owner
- A fuller Positions redesign is planned later; this release keeps the current page working for regionals
