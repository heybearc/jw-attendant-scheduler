# What's New in Version 3.5.0

**Released:** January 29, 2026

---

## ✨ Terminology Update: "Volunteer" Throughout the System

We've updated the terminology across TheoShift to consistently use **"Volunteer"** instead of "Attendant" throughout the application.

### What Changed

**Navigation & Pages:**
- The "Attendants" page is now called **"Volunteers"**
- All menu items and navigation links updated
- Old links automatically redirect to the new pages

**User Interface:**
- Buttons and labels now say "Volunteer" instead of "Attendant"
- Form fields updated with new terminology
- Help documentation updated throughout

**Behind the Scenes:**
- New API endpoints for better performance
- Updated type definitions for improved reliability
- Maintained full backward compatibility

**No action required!** Everything works exactly the same way:

## 🎯 Why This Change?

This update makes TheoShift's terminology more consistent and clearer for all users. The word "Volunteer" better reflects the service provided at assemblies and conventions.
