# What's New in Version 4.7.0

**Released:** February 11, 2026

---

## 🔧 Infrastructure & Stability Improvements

This release focuses on behind-the-scenes improvements to make TheoShift more reliable, faster, and easier to maintain. While you won't see major visual changes, the application is now more stable and performs better.

### What's Better

**✅ More Reliable**
- Fixed an issue where events couldn't be deleted if they had positions assigned
- Events now delete cleanly along with all their related data
- Backup system now runs correctly every day at 2am

**✅ Better Error Messages**
- Improved error handling across the entire application
- More helpful error messages when something goes wrong
- Better logging for troubleshooting issues

**✅ Cleaner Code**
- Removed unnecessary debug messages (78% reduction)
- Standardized how errors are handled across all features
- Improved code quality and maintainability

**✅ Data Recovery**
- Successfully recovered 173 volunteer records from a backup
- Fixed backup system to prevent future data issues
- All volunteer assignment data is now secure

---

## 🐛 Bug Fixes

### Event Deletion
**What was fixed:** Events with positions couldn't be deleted, requiring manual cleanup first.

**Now:** Events delete properly along with all their positions, assignments, and related data automatically.

### Overseer Information Display
**What was fixed:** Circuit Overseer, Assembly Overseer, and Volunteer Overseer names weren't showing in event details.

**Now:** All overseer information displays correctly in the Oversight Command section.

### Backup System
**What was fixed:** Daily backups weren't working due to incorrect database credentials.

**Now:** Backups run successfully every day at 2am and are stored securely.
