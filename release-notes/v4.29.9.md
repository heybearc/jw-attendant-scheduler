# What's New in Version 4.29.9

**Released:** July 28, 2026

---

## 🐛 Bug Fixes

### Multi-day events no longer treat Friday and Saturday as the same shift
Volunteers can serve the same clock times on different days without a false conflict warning.

**What changed:**
- Each shift can have a calendar **Day** (from the event date range)
- Conflicts only apply when two shifts are on the **same day**
- All-day shifts are also limited to that day

**How to use it:**
1. Open the event **Positions** page
2. Edit a shift and choose the day (for example Fri / Sat / Sun)
3. Assign volunteers as usual

---

## 💡 What You Need to Know

- Naming a shift “Friday” is not enough — pick the Day field
- Multi-day events show a reminder if any shifts still have no day set
