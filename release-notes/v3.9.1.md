# What's New in Version 3.9.1

**Released:** February 4, 2026

---

## 🐛 Bug Fixes

### Date Display Issue Fixed

**What was fixed:** Events were showing dates one day earlier than they should (for example, showing May 8 when the actual date was May 9).

**What you'll see now:**
- Event dates display correctly on all pages
- Event selection cards show the right dates
- Event details pages show matching dates
- No more confusion about which day your event is scheduled

**Technical details:** This was a timezone conversion issue that has been completely resolved. Dates now display consistently across the entire application.

---

## ✨ Improvements

### Easier Event Permission Management

**What changed:** When adding users to an event's permission list, you now see a dropdown menu of all available users instead of having to type their email address.

**Benefits:**
- Faster to add users - just select from the list
- No typing errors with email addresses
- See all available users at a glance
- Only shows users who aren't already added

**How to use it:**
1. Go to any event's "Manage Permissions" page
2. Click the "+ Add User" button
3. Select a user from the dropdown
4. Choose their role (Viewer, Coordinator, or Admin)
5. Click "Add User"
