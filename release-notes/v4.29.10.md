# What's New in Version 4.29.10

**Released:** July 28, 2026

---

## 🐛 Bug Fixes

### Auto-assign now fills all days of a multi-day event
Auto-assign used to stop after two shifts per volunteer, so a Friday–Sunday event could leave Sunday empty even when people were available.

**What changed:**
- Auto-assign can give volunteers a third (or more) shift when the event needs it
- Re-running auto-assign can fill remaining days without clearing existing assignments

**How to use it:**
1. Set a **Day** on each shift (multi-day events)
2. Open **Positions** and run **Auto Assign**
3. Check Sunday (or later days) — open slots should fill when people are free

---

## 💡 What You Need to Know

- Volunteers still will not be double-booked on overlapping times the same day
- If Sunday is still short, you may need more people on the roster for that oversight group
