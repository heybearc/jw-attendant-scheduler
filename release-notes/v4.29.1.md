## 🐛 Bug Fixes

### Bulk create positions failed with “already exists”
When adding new positions (for example “Friday - Early Check-in”) to an event that already had positions, Bulk Create incorrectly reused numbers 1, 2, 3… and failed.

**What changed:**
- Bulk Create now sees existing positions and assigns the next free numbers
- Clearer error messages if something still fails

**What you need to do:**
- No action required — try Bulk Create again on the Positions page
