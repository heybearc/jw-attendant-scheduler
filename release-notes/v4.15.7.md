# What's New in Version 4.15.7

**Released:** March 20, 2026

---

## 🐛 Bug Fixes

### Volunteer Login Now Works Correctly
Fixed an issue where volunteers logging in with their PIN would be redirected back to the main login page instead of accessing their dashboard.

**What was fixed:**
- Volunteer sessions now properly store congregation information
- Login redirects work correctly for all volunteers
- No more login loops or authentication errors

**What you need to do:**
- Nothing! Just log in as normal with your name, congregation, and PIN

---

### Bulk PIN Setting Now Works
Fixed an issue where setting PINs for multiple volunteers at once would fail silently.

**What was fixed:**
- Bulk PIN operations (Auto-Generate and Reset) now work correctly
- Individual PIN setting continues to work as before
- All volunteers in the selection will have their PINs updated

**How to use it:**
1. Go to an event's Volunteers page
2. Select multiple volunteers using checkboxes
3. Click "Actions" → "Set PINs"
4. Choose "Auto-Generate PINs" or "Reset All PINs"
5. PINs will be set for all selected volunteers

---

### Event QR Code Now Points to Volunteer Login
Fixed the event QR code to direct volunteers to the correct login page instead of the admin area.

**What was fixed:**
- QR code now links to `/volunteer/login` (volunteer login page)
- Previously linked to admin event page which required admin credentials
- Volunteers can now scan and access the login page directly

**How to use it:**
1. Open any event page
2. Click the "📱 Event QR Code" button
3. Print or display the QR code for volunteers
4. Volunteers scan the code and are taken to the volunteer login page
