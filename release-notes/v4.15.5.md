# What's New in Version 4.15.5

**Released:** February 20, 2026

---

## 🔒 Security & Infrastructure Improvements

### Next.js Upgraded to 15.5.12
Upgraded the core web framework from Next.js 14.2.33 to 15.5.12. This is a major version upgrade that brings significant security improvements, performance enhancements, and resolves the outstanding `next` package security advisory.

**Key improvements in Next.js 15:**
- Improved caching behavior and performance
- Enhanced security hardening
- Better build output and bundle optimization
- Continued Pages Router support (no migration required)
