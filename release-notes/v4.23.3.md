# What's New in Version 4.23.3

**Released:** June 4, 2026

---

## 🐛 Bug Fixes

### IVS page hydration errors

Fixed React hydration errors (#418/#425) on the IVS module that could crash the page or show a 503. The Early Check-In tab no longer renders during server-side load until you open it, and date/time labels render on the client to avoid timezone mismatches.

- No action required — IVS Approvals and Early Check-In should load without console errors.
