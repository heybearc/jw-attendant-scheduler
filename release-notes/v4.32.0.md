# What's New in Version 4.32.0

**Released:** August 4, 2026

---

## ✨ New Features

### Positions day board (preview)
Open **Positions → Try new layout** for a day-based station board. Stations are grouped by day with coverage counts, conflict-aware assign, shift overseer/keyman, edit times, notifications, and setup tools (bulk create / apply template).

**What you can do:**
- Staff one day at a time with underfilled stations highlighted
- Collapse filled stations and expand when you need detail
- Run **Auto-assign for this day only** (not the whole event)
- On phones, use the single **Actions…** menu instead of a long button row

**How to use it:**
1. Open an event → **Positions**
2. Choose **Try new layout**
3. Switch days with tabs or the coverage chips above them

Classic Positions remains the default until you publish the new layout.
