# What's New in Version 4.15.6

**Released:** March 20, 2026

---

## ✨ New Features

### Multiple Volunteers Per Shift
You can now assign multiple volunteers to the same shift! This makes it easier to staff positions that need extra help during busy times.

**What you can do:**
- Assign as many volunteers as needed to any shift
- See all assigned volunteers listed together
- Easily add more volunteers with the "+ Assign Another Volunteer" button

**How to use it:**
1. Go to the Positions page for your event
2. Click on a shift that already has a volunteer assigned
3. Click the "+ Assign Another Volunteer" button
4. Select the additional volunteer from the list
5. Click "Assign Volunteer"

**Note:** Overseer and Keyman roles are still limited to one per shift, but regular volunteers can now have multiple assignments.

---

## 🐛 Bug Fixes

### Early Check-In Tab Visibility
Fixed an issue where the Early Check-In tab was showing for all volunteers, even when the IVS module wasn't enabled for the event.

**What changed:**
- The Early Check-In tab now only appears when the IVS module is enabled in event settings
- Volunteers must also have IVS approval status to see the tab

### Auto-Assign Button Always Visible
The Auto-Assign button on the Positions page is now always visible to administrators, making it easier to discover this feature.

**What changed:**
- Button is always shown (previously hidden when no volunteers were available)
- Button is disabled with a helpful tooltip when no unassigned volunteers are available
- Shows the count of unassigned volunteers when available

## 💡 What You Need to Know

**No action required!** These improvements are automatically available.

**Multiple volunteers per shift:**
- This feature makes it easier to handle high-traffic positions
- You can still assign just one volunteer if that's all you need
- The system prevents you from assigning the same volunteer twice to the same shift

**Early Check-In:**
- If you don't see the Early Check-In tab, check that the IVS module is enabled in your event settings
- Contact your event coordinator if you need access
