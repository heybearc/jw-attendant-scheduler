# What's New in Version 4.27.0

**Released:** July 25, 2026

---

## ✨ New Features

### Remove department from IVS contacts

On **IVS Approvals → Department contacts**, use **Remove department** to drop a misspelled or unused department name from the list. Contact-only names leave the dropdown permanently. Names still used on volunteer rows warn you to rename those volunteers first (bulk **Change department name**).

**Clear contact info** still clears overseer/assistant details without removing the department name.

### Phone number formatting

Phone fields (department contacts, volunteer add/edit, volunteer profile) format as **(XXX) XXX-XXXX** as you type or paste — including numbers with `+1`. The same format is applied when saving or importing.

---

## 🐛 Bug Fixes

### Pending status with an approval date

Changing an IVS volunteer back to Pending (or Requested / Not Approved) now clears the approval date. Exports only show **APPROVAL DATE** when status is Approved. Existing mismatched rows were cleaned up.
