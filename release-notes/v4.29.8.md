# What's New in Version 4.29.8

**Released:** July 28, 2026

---

## ✨ New Features

### Assign an overseer to a shift
You can now set a different overseer or keyman for each shift on a position.

**What you can do:**
- Assign an overseer or keyman on a specific shift
- Keep a position-wide default when every shift shares the same oversight

**How to use it:**
1. Open the event **Positions** page
2. On a shift, choose **+ Assign Overseer** or **+ Assign Keyman**
3. Or open assign and pick **Overseer** / **Keyman** from the role menu

### Set volunteers needed in bulk
When you create or update shifts for many positions at once, you can set how many people each shift needs.

**What you can do:**
- Set capacity while applying a template or creating a custom shift
- Update volunteers needed on existing shifts across selected positions

**How to use it:**
1. Select the positions you want
2. Open bulk edit
3. Use **Volunteers needed** on create/template, or **Update Volunteers Needed** for existing shifts

---

## 💡 What You Need to Know

- Shift overseer is preferred when assigning volunteers; position oversight is still the fallback
- Capacity updates apply only to the positions you selected
