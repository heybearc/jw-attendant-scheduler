# What's New in Version 4.21.0

**Released:** May 6, 2026

---

## 🐛 Bug Fixes

### Event documents

Uploaded documents should open reliably for volunteers and staff, including when the system runs on more than one server. If a file is ever missing from storage, the documents list will clearly show **File missing** so you know to upload again instead of seeing a blank error.

### Updating volunteers

Saving changes to a volunteer on the event volunteers page should match what you see after refresh. You should no longer get an error message when the update actually worked.

### Loading pages (especially Volunteers)

Some browsers showed confusing **503** or load failures because of how offline mode interacted with normal pages. Routine screens should load without that false error.

---

## 💡 What You Need to Know

- **Administrators:** If you use shared storage for uploads, your hosting environment should define where files live (`THEOSHIFT_UPLOADS_ROOT`). Your administrator handles that on the server.
- **Everyone else:** No change to how you use the app day to day.
