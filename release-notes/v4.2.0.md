## 🔧 Technical Changes

### Database Schema
```sql
-- New locations table
CREATE TABLE locations (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  address TEXT,
  latitude DOUBLE PRECISION,
  longitude DOUBLE PRECISION,
  notes TEXT,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  created_by TEXT,
  usage_count INTEGER DEFAULT 0
);

-- Foreign key added to events table
ALTER TABLE events ADD COLUMN location_id TEXT REFERENCES locations(id);
CREATE INDEX idx_events_location_id ON events(location_id);
```

### Prisma Schema Updates
- Added `locations` model with proper field mappings
- Added `locationRef` relation to `events` model
- Configured `@map` directives for snake_case database columns

### API Endpoints
- `GET /api/locations` - List all active locations with search/filter
- `POST /api/locations` - Create new location
- `GET /api/locations/[id]` - Get location details
- `PUT /api/locations/[id]` - Update location
- `DELETE /api/locations/[id]` - Soft delete location
- `PUT /api/events/[id]` - Updated to support location relations

### Environment Configuration
- Added `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` for client-side Maps integration
