# What's New in Version 4.15.4

**Released:** February 20, 2026

---

## 🔒 Security Improvements

### Removed Vulnerable Excel Library
Replaced the `xlsx` package (abandoned, multiple unfixable security vulnerabilities) with `ExcelJS` across all Excel export and import features. All Excel functionality works identically — this is a purely internal security improvement with no user-facing changes.

**Affected features:**
- IVS volunteer export
- IVS early check-in export and import
- Oversight report Excel export
- Early check-in report export

---

## 💡 What You Need to Know

- No action required — all Excel exports and imports work exactly as before.
- No user-facing functionality has changed.
