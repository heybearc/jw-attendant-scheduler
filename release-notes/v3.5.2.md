# What's New in Version 3.5.2

**Released:** January 30, 2026

## 🐛 Bug Fix

### Admin Portal Button Visibility

Fixed an issue where the Admin Portal button was not appearing for some admin users.

**What was fixed:**
- Admin portal button now appears correctly on the event selection page
- Button now appears in the navigation menu for all admin users
- Fixed case sensitivity issue with admin role detection

**What you'll see:**
- If you're an admin user, you'll now see the "🛡️ Admin Portal" button in the top navigation
- Button appears on the event selection page (top-left corner)
- Button appears in the navigation bar when viewing events

---

## 💡 What You Need to Know

- **No action required** - The fix is automatic
- If you previously couldn't see the Admin Portal button, it will now appear
- All admin functionality remains the same
