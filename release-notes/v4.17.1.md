# What's New in Version 4.17.1

**Released:** 2026-04-28

---

## 🐛 Bug Fixes

### Overseer/Keyman Removal Works Reliably
We fixed an issue where removing an overseer or keyman assignment could fail when related assignments already existed.

**What this means for you:**
- You can now clear overseer/keyman assignments without getting blocked by stale links
- Cleanup of volunteer oversight assignments is more reliable

### Better Error Messages on Volunteers Page
If an update fails, the volunteers page now shows a clearer message from the server instead of a generic error popup.

- This release focuses on reliability improvements for volunteer oversight management
