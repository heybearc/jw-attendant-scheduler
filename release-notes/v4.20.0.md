# What's New in Version 4.20.0

**Released:** May 5, 2026

---

## ✨ New Feature: In-App Event Chat

TheoShift now includes **event-scoped chat** so staff and volunteers can communicate in one place.

### What you can do

- **Event Announcements**: see important updates in a single channel
- **Event General**: coordinate with others working the event
- **Position channels**: (when available) talk with the people assigned to the same position

### Staff-only chat

Event staff can also use **Staff Internal** chat for coordination that volunteers cannot see.

---

## 🧰 Staff Tools (Moderation)

Staff can:

- **Pin** a key message to the top of a channel (instructions, reminders, etc.)
- **Mute** a user or volunteer in a channel (temporary)
- **Delete** messages when needed (removes it for everyone)

---

## 💡 What You Need to Know

- Volunteers access chat through their **magic link dashboard** (no extra login steps).
- If you don’t see chat for an event, it may not be enabled/configured yet.

---
