# What's New in Version 4.9.0

**Released:** February 16, 2026

---

## ✨ New Features

### Event Oversight User Linking

You can now link event oversight roles (Department Overseer, Assistants, and Keymen) directly to system users! This makes it easier to manage contact information and ensures accuracy.

**What you can do:**
- Link oversight roles to existing system users
- Automatically populate contact information from user profiles
- Maintain accurate phone numbers and emails
- Still use manual entry for non-system users

**How to use it:**
1. Navigate to your event and click **Edit Event**
2. In the Oversight section, click **Link to User** next to any role
3. Search for and select a system user
4. Contact information auto-fills from their profile
5. Click **Unlink** anytime to switch back to manual entry

---

### Automatic Phone Number Formatting

All phone number fields now automatically format as you type, making data entry faster and more consistent.

**What you'll see:**
- Phone numbers automatically format to `(XXX) XXX-XXXX`
- Works for all phone fields: users, oversight roles, and volunteers
- Existing phone numbers are formatted when pages load
- Linked user phone numbers are formatted automatically

**No action required** - formatting happens automatically!

### Improved User Management

The user management interface has been enhanced with better pagination and visibility.

**What's improved:**
- **Pagination works correctly** - Navigate between pages of users smoothly
- **Actions menu always visible** - Dropdown menus no longer hidden behind other elements
- **Better search experience** - Search results display properly with full functionality

## 🐛 Bug Fixes

### User Management Pagination

**What was fixed:**
- Pagination now correctly advances to the next/previous page
- Search filters are preserved when navigating pages
- Page numbers update accurately

### Actions Dropdown Visibility

Fixed an issue where the Actions dropdown menu in user management was hidden behind other page elements.

**What was fixed:**
- Actions menu now appears above all other elements
- Dropdown is fully visible even with few search results
- No more scrolling to see menu options

## 💡 What You Need to Know

### Phone Number Auto-Population

When linking a system user to a volunteer record, their phone number will automatically populate if they don't already have one in their user profile. This helps keep contact information synchronized.

### Oversight Contact Information

When you link an oversight role to a system user, the contact fields (name, phone, email) become read-only and are managed through the user's profile. To update this information, edit the user's profile in User Management.

### No Action Required

All improvements are automatically available. Your existing data is preserved and will be formatted when you view or edit it.
