# What's New in Version 4.18.0

**Released:** 2026-04-29

---

## ✨ New Features

### Grouped Attendance Counting
You can now combine multiple stations into a single count group (for example, "Section A") and enter one shared total.

**What you can do:**
- Assign a primary and secondary counter for each group
- Let either assigned counter submit the agreed total
- Keep station coverage clear while reducing duplicate data entry

**How to use it:**
1. Open an event and go to `Count Times`
2. Build groups by selecting stations for each section
3. Assign primary and secondary counters
4. Save groups, then submit one count per group from the volunteer dashboard

---

### Admin Volunteer Dashboard Preview (Read-Only)
Admins can now preview the volunteer dashboard experience directly from event pages.

**What you can do:**
- Choose a volunteer and start a preview session
- Confirm exactly what that volunteer can see
- Validate count assignments before the event

**How to use it:**
1. Open any event page
2. Select a volunteer in the `View as volunteer` dropdown
3. Click `Start View-As`
4. Review the volunteer dashboard preview, then click `Exit Simulation` when done

---

## 🐛 Bug Fixes

### Oversight Dashboard API
Resolved a missing oversight endpoint that could cause a 404 error on event dashboard load.

### View-As Reliability
Fixed multiple routing and authorization edge cases so preview sessions stay on the intended volunteer dashboard.

## 💡 What You Need to Know

- No migration steps are required for normal use

- View-as preview remains read-only by design to protect live event data
