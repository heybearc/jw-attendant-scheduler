# What's New in TheoShift v4.2.1

**Released:** February 9, 2026

---

## 🎯 Overview

This patch release improves the release notes page with modern search and filtering capabilities, making it easier to find and review past updates.

---

## ✨ What's New

### 📋 Improved Release Notes Page

**The Problem:**
The release notes page showed all releases in a long list, making it difficult to find specific versions or types of updates.

**What We Fixed:**
The release notes page now has professional search and filtering tools!

**What You Can Do:**

**Search for Releases**
- Type in the search bar to find releases by version, title, or content
- Results update instantly as you type
- See how many releases match your search

**Filter by Release Type**
- Click "All" to see everything
- Click "🚀 Major" to see major version updates
- Click "✨ Minor" to see new features
- Click "🔧 Patch" to see bug fixes and improvements

**Organized by Version**
- Releases are grouped by major version (v4.x, v3.x, etc.)
- See how many releases in each version group
- Easier to track the evolution of TheoShift

**Collapsible Releases**
- Click any release to expand and see full details
- Click again to collapse
- Only the latest release is expanded by default
- Reduces scrolling and makes scanning easier

**Better Visual Design**
- Color-coded badges for release types
- Clean, modern layout
- Improved spacing and typography
- Professional appearance

**How to Use It:**
1. Go to Help → Release Notes
2. Use the search bar to find specific releases
3. Click the filter buttons to see only certain types
4. Click any release header to expand or collapse it
5. Scroll through version groups to see history

## 🔧 Bug Fixes

Fixed an issue where some releases were missing their release dates. All releases now show their dates correctly.
