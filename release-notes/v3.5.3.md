# What's New in Version 3.5.3

**Released:** January 30, 2026

---

## ✨ New Features

### Session Management System

We've added a comprehensive session management system to help administrators monitor and maintain active user sessions.

**What you can do:**
- View all active user sessions in one place
- See which users are currently online
- Monitor session activity and expiration dates
- Clean up old or excessive sessions with one click

**How to access it:**
1. Log in as an admin user
2. Go to Admin Portal
3. Click "Session Management" in the sidebar
4. View session statistics and manage sessions

**New cleanup tools:**
- **Cleanup Expired:** Removes sessions inactive for 30+ days
- **Cleanup Excessive:** Keeps only the 5 most recent sessions per user

---

## 🐛 Bug Fixes

### Session Accumulation Fixed

Fixed an issue where users were accumulating hundreds of active sessions over time.

**What was fixed:**
- Sessions now properly reuse across browser tabs
- Opening multiple tabs no longer creates multiple sessions
- Session tracking now uses browser-wide storage instead of per-tab storage
- Orphaned sessions (from deleted users) are automatically cleaned up

**What you'll see:**
- Much lower session counts (typically 1-3 per user instead of hundreds)
- Better performance and reduced database load
- More accurate "who's online" tracking

### Login Form Improvements

Enhanced the login form for better browser compatibility and password manager integration.

**What was fixed:**
- Added proper autocomplete attributes for email and password fields
- Improved password manager detection and autofill
- Eliminated browser console warnings

### Admin Portal Button

Fixed an issue where some admin users couldn't see the Admin Portal button.

**What was fixed:**
- Admin Portal button now appears consistently for all admin users
- Fixed case sensitivity issues with admin role detection

---

## 💡 What You Need to Know

**No action required** - All improvements are automatic.

**For administrators:**
- Visit the new Session Management page to see current session statistics
- Use the cleanup buttons if you notice excessive sessions
- Sessions will now automatically stay under control going forward

**Session behavior:**
- One session per browser (shared across all tabs)
- Different browsers or devices create separate sessions
- Sessions expire after 30 days of inactivity
- Logging out properly closes your session
