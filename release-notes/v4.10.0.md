# What's New in Version 4.10.0

**Released:** February 16, 2026

---

## ✨ New Features

### IVS Early Check-In Dashboard Integration

IVS team members can now check in volunteers directly from their dashboard!

**What you can do:**
- Check in approved IVS volunteers from a dedicated dashboard tab
- View pending and checked-in volunteers in organized sections
- Search volunteers by name or congregation
- See real-time updates every 5 seconds
- Export check-in reports
- Undo check-ins if needed

**How to use it:**
1. Log in to your volunteer dashboard
2. Click the **"✅ Early Check-In"** tab (only visible to IVS team members)
3. Search for volunteers or browse the pending list
4. Tap **"Check In"** to check in a volunteer
5. View checked-in volunteers in the history section

**Mobile-friendly:**
- Works on phones and tablets
- Large, easy-to-tap buttons
- Collapsible sections to save screen space
- Install as a PWA app on your home screen

## 🎨 Improvements

### Collapsible Section Layout
- **Pending Check-In** section (orange) - Shows volunteers waiting to be checked in
- **Checked In** section (green) - Shows completed check-ins with timestamps
- Stats bar showing pending, checked-in, and total eligible counts
- Live indicator showing last update time

### Access Control
- Only IVS team members (volunteers with position assignments) can access check-in features
- Secure API endpoints verify team member status
- Consistent access control across all check-in actions

## 💡 What You Need to Know

**For IVS Team Members:**
- The Early Check-In tab appears automatically on your dashboard
- You can use either the dashboard tab or the separate check-in page
- Both interfaces show the same real-time data
- Check-ins sync across all devices every 5 seconds

**For Overseers:**
- The overseer's IVS check-in page remains unchanged
- Both volunteer and overseer interfaces use the same data
- All check-ins are tracked with timestamps and who performed them

**Internet Connection:**
- Currently requires internet connection to check in volunteers
- Offline queue functionality is planned for future release
- Use mobile hotspot as backup at conventions
