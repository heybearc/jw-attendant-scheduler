# What's New in Version 3.7.0

**Released:** January 31, 2026

---

## ✨ Mobile Experience Overhaul

TheoShift now works beautifully on your phone or tablet! We've completely redesigned the mobile experience to make managing events on-the-go easier than ever.

### 📱 What's New for Mobile Users

**Touch-Friendly Navigation**
- New bottom navigation bar keeps important features at your fingertips
- Quick access to Dashboard, Volunteers, Positions, and More
- Hamburger menu for additional options
- Navigation stays visible as you scroll

**Optimized Tables and Lists**
- Tables automatically convert to easy-to-read cards on mobile
- Swipe left or right to see more information
- Clear labels show what each piece of information means
- No more squinting at tiny text!

**Smart Forms**
- Larger buttons and inputs sized perfectly for tapping
- Your phone's keyboard automatically matches the field type (email, phone, etc.)
- Autocomplete helps you fill forms faster
- Text sized to prevent accidental zooming

**Full-Screen Modals**
- Pop-up windows slide up smoothly from the bottom
- Large, easy-to-tap buttons
- Action buttons stack vertically for better access
- Comfortable scrolling within modals

**Touch Gestures**
- Pull down from the top to refresh any page
- Swipe actions on lists for quick edits (where available)
- Natural, intuitive interactions

**Optimized Dashboards**
- Information cards stack vertically for easy scrolling
- Statistics display in a clean 2-column grid
- Charts sized appropriately for mobile screens
- Full-width action buttons for easy tapping

## 🔧 Bug Fixes

### Volunteer Management
Fixed an issue where deleting volunteers would show an error message. Volunteers can now be removed from events without any problems.

### Event Management
Fixed an issue where deleting events would fail. Events can now be deleted properly when needed.

### Offline Support
Fixed a problem with the service worker that could cause errors when loading the app. The app now works more reliably, especially when going offline and back online.
