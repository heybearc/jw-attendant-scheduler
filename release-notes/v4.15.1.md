# What's New in Version 4.15.1

**Released:** February 20, 2026

---

## 🐛 Bug Fixes

### Assignment Notification Emails
Fixed a critical issue where assignment notification emails (created, updated, cancelled, and reminder) were failing silently due to an incorrect field reference. All assignment emails now send correctly.

### Volunteer Reminder Emails
Fixed the automated reminder cron job which was completely broken — reminders were never being sent to volunteers. Reminders will now be delivered as expected.

### Feedback Submission
Fixed feedback submission which was crashing due to incorrect database relation references. Volunteers and admins can now submit feedback successfully.

### Admin User Management
Fixed the Admin → Users page which was failing to load due to an incorrect database relation name.

### Event Cloning
Fixed the event clone feature which was referencing non-existent fields. Events can now be cloned correctly.

### Volunteer Profile Updates
Fixed a type error in the volunteer profile update flow that could cause PIN updates to fail.

### Volunteer Dashboard
Fixed a potential crash on the volunteer dashboard when certain date fields were null.

### Position Management
Fixed the positions page bulk-create and assignment include queries which were referencing incorrect relation names.

### Document Publishing
Fixed the document publish email flow which had an unnecessary filter causing a type error.

---

## 💡 What You Need to Know

- No action required — all fixes are automatic.
- If you previously submitted feedback and didn't receive confirmation, please try again.
- Assignment reminder emails will now arrive as scheduled.
