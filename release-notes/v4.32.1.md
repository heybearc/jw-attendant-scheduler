# What's New in Version 4.32.1

**Released:** September 5, 2026

---

## 🐛 Bug Fixes

### Event cloning — volunteers and oversight
Cloning an event with volunteer links now keeps those people on the Volunteers tab (not only on Positions). Oversight details (department overseer contacts, keymen, and position oversight) copy when you leave Oversight checked.

### Event cloning — shift days and capacity
Multi-day shift dates and how many people each shift needs are preserved on the clone, so the day board stays accurate.

### Event cloning — lanyards and permissions
Lanyard badges start fresh as available (checkout state is not carried over). Position-scoped permissions are remapped to the new event’s positions.

---

## 💡 What You Need to Know

- Re-clone any event that was duplicated before this fix if volunteers or oversight looked wrong.
- No other action required for existing events.
