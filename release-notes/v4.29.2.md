**Released:** July 26, 2026

## 🐛 Bug Fixes

### Adding a volunteer failed when the email already existed
If someone was already in TheoShift (from another event or earlier import), adding them to an event with the same email returned an error instead of linking them.

**What changed:**
- TheoShift finds the existing volunteer by email and adds them to this event
- If they are already on the event, you get a clear message instead of a failure

**What you need to do:**
- No action required — try adding the volunteer again

Event membership stays separate: volunteers only appear on events they are linked to.
