# What's New in Version 4.15.2

**Released:** February 20, 2026

---

## 🐛 Bug Fixes

### Availability Request Emails Now Send Correctly
Sending availability request emails to volunteers was silently failing for all recipients. This is now fixed and emails will deliver as expected.

### Volunteer Search Finds Overseers and Keymen
Typing "overseer" or "keyman" in the volunteer search bar now correctly returns volunteers who have those event-specific roles assigned.

### Overseer/Keyman Removed from Forms of Service Filter
The volunteer filter panel no longer shows "Overseer" and "Keyman" as Forms of Service options — these are event-specific roles, not global qualifications.

### Bulk Volunteer Actions Fixed
Bulk activate/deactivate and bulk remove from event were broken due to a database naming mismatch. Both actions now work correctly.

### PDF and Excel Exports Show Volunteer Names
Exporting positions to PDF or Excel was showing blank names in the assigned volunteers column. Names now appear correctly in all exports.

### Legacy Overseer/Keyman Tags Cleaned Up
Volunteers who previously had "Overseer" or "Keyman" stored in their global Forms of Service field have been cleaned up. These roles are now correctly tracked only as event-specific flags.

---

## 💡 What You Need to Know

- No action required — all fixes are automatic.
- If you previously saw blank names in PDF/Excel exports, re-export to get correct results.
- Availability request emails will now send successfully.
