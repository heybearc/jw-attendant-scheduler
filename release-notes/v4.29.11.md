# What's New in Version 4.29.11

**Released:** July 28, 2026

---

## ✨ New Features

### Fill large shifts even when one overseer has a small team
If a shift needs more people than that overseer’s group has (for example need 6, group has 3), staffing can still complete.

**What changed:**
- **Auto-assign** fills from the matching overseer/keyman first, then uses volunteers from other groups for leftover slots
- **Manual assign** shows the full roster — matching people first, others labeled “Other group”

**How to use it:**
1. Set shift overseers and volunteer oversight as usual
2. Run **Auto Assign**, or open **Assign** and pick anyone (including “Other group”)
3. Check the auto-assign summary for how many were matched vs filled from other groups

---

## 💡 What You Need to Know

- Preferred group is still used first — cross-group fill is only for remaining capacity
- Time conflicts still apply across days when a Day is set on each shift
