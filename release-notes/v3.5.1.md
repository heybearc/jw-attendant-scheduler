# What's New in Version 3.5.1

**Released:** January 30, 2026

---

## 🔧 Internal Improvements

This release focuses on behind-the-scenes improvements to make TheoShift more reliable and maintainable.

### Testing Infrastructure
We've significantly improved our automated testing system to ensure higher quality and faster releases:

- **Cleaned up test suite** - Removed outdated diagnostic tests that were no longer needed
- **Improved test reliability** - Fixed test configuration issues that were causing false failures
- **Better test organization** - Created clear policies for managing tests going forward

### What This Means for You

✅ **More reliable releases** - Our improved testing catches issues before they reach you  
✅ **Faster updates** - Streamlined test suite means quicker verification of new features  
✅ **Better quality** - All code changes are now thoroughly tested before deployment
