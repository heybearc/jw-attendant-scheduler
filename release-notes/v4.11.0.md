# What's New in Version 4.11.0

**Released:** February 17, 2026

---

## ✨ New Features

### Event-Specific Settings & Modules

You can now customize each event individually without relying on templates! Each event has its own settings that control which features are available.

**What you can do:**
- Enable or disable specific modules per event (Positions, Documents, Announcements, etc.)
- Customize terminology for each event (e.g., "Volunteers" vs "Attendants")
- Configure event settings directly in the event edit page

**How to use it:**
1. Go to any event and click **Edit Event**
2. Click the **Modules & Features** tab
3. Toggle modules on/off and customize terminology
4. Save your changes

**What you'll see:**
- Navigation tabs automatically hide/show based on your module selections
- Dashboard cards only appear for enabled modules
- Cleaner, more focused interface for each event

---

### Enhanced Event Cloning

When cloning an event, you now have full control over what gets copied!

**What you can do:**
- Choose exactly what to clone: positions, volunteers, assignments, permissions, etc.
- Clone just the structure without the people
- Clone everything for a complete duplicate

**How to use it:**
1. Go to any event and click **Edit Event**
2. Click the **Clone Event** button
3. Select which items you want to copy
4. Click **Clone Event** to create the duplicate

**What you'll see:**
- A modal with checkboxes for each cloneable item
- Clear descriptions of what each option includes
- Volunteers are unchecked by default for easier sharing

## 🐛 Bug Fixes

### Event Detail Page Loading

**Fixed:** Events now load correctly without showing a blank gray screen.

**What was broken:** Some events would show a blank page instead of the event dashboard.

**How it's fixed:** Improved page rendering to ensure content always displays properly.

---

### Shift Template Application

**Fixed:** Applying shift templates to multiple positions now works correctly.

**What was broken:** Selecting multiple positions and applying a shift template would fail with an error.

**How it's fixed:** Corrected the communication between the positions page and the server.

---

### Oversight Page Display

**Fixed:** The oversight page now loads and displays data correctly.

**What was broken:** The oversight page would show an error instead of oversight information.

**How it's fixed:** Improved how oversight data is loaded and displayed.

---

## 💡 What You Need to Know

**No action required!** All changes are backward compatible:
- Existing events continue to work as before
- If you haven't customized an event's modules, it will use the same defaults as before
- All your existing data, positions, and volunteers are preserved

**Module Enforcement:**
- If you disable a module (like Positions), that tab will disappear from the event navigation
- You can always re-enable modules later if needed
- This helps keep the interface clean and focused on what you actually use
