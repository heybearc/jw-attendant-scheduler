# What's New in Version 4.23.4

**Released:** June 4, 2026

---

## 🐛 Bug Fixes

### IVS Add volunteer

Adding a volunteer who already exists in the global registry (same name, different congregation) no longer returns a server error. TheoShift reuses the existing person record and shows a clear message if they are already on the IVS list for this event.

---

## 💡 What You Need to Know

- No action required — use **Add volunteer** as before; duplicate adds show a friendly message instead of a 500 error.
