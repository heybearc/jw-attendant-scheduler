# What's New in Version 4.14.0

**Released:** February 19, 2026

---

## ✨ New Features

### Volunteer Bottom Navigation
Volunteers now have a navigation bar at the bottom of every screen — no more scrolling back to the top to switch pages.

**What you'll see:**
- A fixed bar at the bottom with three tabs: **Dashboard**, **Check-In**, and **Events**
- The current page is highlighted in blue so you always know where you are
- Works perfectly on iPhone and Android, including the home indicator area

**How to use it:**
1. Log in as a volunteer at `/volunteer/login`
2. The navigation bar appears automatically on every page
3. Tap any tab to switch instantly

---

### Global Announcements (Admin)
Administrators can now post system-wide messages that appear across the application — perfect for maintenance notices, important reminders, or urgent alerts.

**What you can do:**
- Create announcements with a title, message, and type (Info, Warning, or Urgent)
- Set start and end dates to control when an announcement appears
- Toggle announcements on or off without deleting them
- Color-coded by type: blue for Info, yellow for Warning, red for Urgent

**How to use it:**
1. Go to **Admin → Global Announcements**
2. Click **New Announcement**
3. Fill in the title, message, and choose a type
4. Toggle it **Active** when you're ready for users to see it

---

### In-App Document Viewer
Documents now open in a full-screen viewer inside the app instead of opening a new browser tab. This fixes a common issue on iPhone where documents would get "trapped" in a new tab.

**What you'll notice:**
- Tap any document — it opens right in the app
- A back button returns you to the document list
- PDFs display inline, images show full-screen, other files offer a download button
- Works smoothly on both mobile and desktop

---

## 🐛 Bug Fixes

### Event Navigation Tabs Now Always Visible
The navigation tabs at the top of event pages (Positions, Volunteers, Announcements, etc.) were sometimes missing. This has been fixed — all tabs now appear correctly on every event page.

### Overseer Dropdown Now Shows Correct People
The dropdown for assigning an overseer to a position was sometimes showing an empty list. This has been fixed — the correct people now appear based on their actual overseer status.

### Dashboard Counts Now Accurate
The statistics on the event dashboard were sometimes showing doubled numbers. This has been fixed — all counts are now accurate.

### Assistant Overseers Can Create Events
Assistant Overseers were getting a "permission denied" error when trying to create new events, even though they have permission to do so. This has been fixed.
