# What's New in Version 4.26.1

## 🐛 Bug Fixes

### Volunteers multi-select checkboxes

On the **Volunteers** page, bulk-selection checkboxes now check immediately when you click them — same fix previously applied to IVS Approvals. You no longer need to click another row before the first checkmark appears.

Shift+click range selection on the current page still works as before.
