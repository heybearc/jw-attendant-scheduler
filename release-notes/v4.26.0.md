# What's New in Version 4.26.0

**Released:** July 20, 2026

---

## ✨ New Features

### IVS import template (status + early entry)

On **IVS Approvals → Import**, download a spreadsheet template with:

- **Required:** NAME, CONGREGATION
- **Optional:** DEPARTMENT, STATUS, EARLY ENTRY (or separate Fri/Sat/Sun early-entry columns)

You can import a full working list that already has approval status and early-entry days. Re-importing the same person updates those fields when they are present in the file.

---

## 🐛 Bug Fixes

### Volunteer Early Check-In day counts

When simulating a volunteer (or using the volunteer dashboard as IVS team), day tabs (Fri / Sat / Sun) now show the same pending and checked-in counts as the admin Early Check-In view.

---

## 📚 Help & docs

- **Help → IVS Module** updated for the new import columns, department contacts, and Early Check-In search/filters
- README feature list and version history updated

## 💡 What You Need to Know

- STATUS and EARLY ENTRY are optional — leave blank to skip
- Request round still comes from the import dialog (one round per file)
- Elders still auto-approve when STATUS is blank
